# App Store — Screenshots (6 frames to capture)

Capture on a real iPhone (or the 6.7"/6.9" simulator) in the TestFlight/native
build. Required sizes: **6.9" (1320×2868)** and **6.5" (1242×2688)**; a 5.5" set
is optional. Portrait. No status-bar clutter — use a clean device or the
simulator's clean status bar.

Order matters — the first two carry the store; lead with the bubble.

1. **The front door.** Home screen: "The house is a bit much." + the speak/type
   field with the mic. Caption idea: *"Say what your home needs."*
2. **It understands you.** The field with a sentence typed and the tags +
   "About how long? / Products?" chips showing. Caption: *"We ask only what's
   missing."*
3. **Real students.** The "Meet the helpers" cards (real ID-verified faces).
   Caption: *"Trusted local students — you see who's coming."*
4. **The request sheet.** The booking sheet: phone + the "you'll get a name when
   a student says yes · no card yet" line + the 4-digit-code reassurance.
   Caption: *"No card until a student says yes."*
5. **Safe at the door.** The Safety page (or the arrival-code explainer).
   Caption: *"A 4-digit code at your door before they start."*
6. **Earn as a student.** The /join screen ("Make rent between lectures").
   Caption: *"Students: small jobs, near you, on your time."*

Tips:
- Shoot with real approved-helper data so faces are genuine (never mock faces).
- Keep the same one accent (sage) and cream background across all six so the set
  reads as one app.
- Optional: add a thin caption bar above each frame in your screenshot tool —
  don't bake captions into the app UI.
